# 00 — Data acquisition

This module contains scripts used to retrieve the public sequencing data, reference files, blacklist regions, and previously published datasets required for the Antennapedia ChIP-seq analysis.

Its purpose is limited to **data acquisition and source-data preparation**. Downstream quality control, alignment, peak calling, genomic annotation, motif analysis, dataset comparison, and plotting are handled in later workflow modules.

## Scripts

### `01_download_FlagAntp_GEO.sh`

Downloads the raw sequencing data generated for this study.

Samples:

- Flag-Antp replicate 1 — `GSM9491492`
- Flag-Antp replicate 2 — `GSM9491493`
- Flag-Antp input — `GSM9491494`

These samples correspond to two Flag-Antp ChIP-seq biological replicates and one input DNA sample.

The script should retrieve the underlying sequencing runs and generate the FASTQ files used for downstream processing.

---

### `02_download_GFP_Antp_embryo.sh`

Downloads the previously published GFP-Antp embryonic ChIP-seq data.

Files:

- GFP-Antp replicate 1 — `ENCFF194GDT`
- GFP-Antp replicate 2 — `ENCFF716FHU`
- GFP-Antp input — `SRR28101828`

The GFP-Antp embryonic ChIP-seq reads are single-end 50-bp reads (SE50).

The ENCODE files can be downloaded directly using their file accessions. The input is retrieved from SRA.

---

### `03_download_GFP_Antp_wing_disc.sh`

Downloads the previously published GFP-Antp wing-disc ChIP-seq data.

Samples:

- Antp-GFP ChIP, wing disc — `GSM3578082`
- Antp-GFP input, wing disc — `GSM3578083`

The script should retrieve the underlying sequencing runs associated with these GEO samples and generate the FASTQ files used for downstream processing.

---

### `04_download_FAIRE.sh`

Downloads the published FAIRE-seq peak BED files used as accessible-chromatin references.

Datasets:

- Embryos 2–4 h — `GSM948712`
- Embryos 6–8 h — `GSM948713`
- Embryos 16–18 h — `GSM948714`
- Wing discs — `GSM948717`

The downloaded peak files are:

```text
GSM948712_e2-4hr_FAIRE_peaks.bed.gz
GSM948713_e6-8hr_FAIRE_peaks.bed.gz
GSM948714_e16-18hr_FAIRE_peaks.bed.gz
GSM948717_wing_disc_FAIRE_peaks.bed.gz
```

These published BED files are in the **dm3 genome assembly**.

They must therefore be converted to dm6 before they are used together with the Antp datasets generated or analyzed in dm6 coordinates.

---

### `05_download_dm6_reference.sh`

Downloads the Drosophila melanogaster dm6 reference files from UCSC.

Required files:

```text
dm6.fa.gz
dm6.chrom.sizes
```

These files provide the reference genome sequence and chromosome sizes used by downstream modules.

The Bowtie2 index is not generated in this module; alignment-specific preparation belongs in the alignment module.

---

### `06_download_dm6_blacklist.sh`

Downloads the dm6 blacklist:

```text
dm6-blacklist.v2.bed.gz
```

from the Boyle Lab Blacklist repository.

The blacklist is used later during read filtering to remove reads overlapping problematic genomic regions.

---

### `07_download_liftover_chain.sh`

Downloads the UCSC chain file required to convert the published FAIRE-seq peak coordinates from dm3 to dm6:

```text
dm3ToDm6.over.chain.gz
```

---

### `08_liftover_FAIRE_dm3_to_dm6.sh`

Converts the downloaded FAIRE-seq BED files from dm3 to dm6 using UCSC/Kent `liftOver`.

Conceptually:

```text
FAIRE peaks in dm3
        |
        v
dm3ToDm6.over.chain.gz
        |
        v
UCSC liftOver
        |
        v
FAIRE peaks in dm6
```

The script should retain the `unmapped` output generated by `liftOver` so that failed coordinate conversions can be inspected and documented.

## Data types downloaded in this module

Two different types of public input data are retrieved:

### Raw sequencing reads

- Flag-Antp ChIP-seq
- GFP-Antp embryonic ChIP-seq
- GFP-Antp wing-disc ChIP-seq

These datasets are retrieved as FASTQ files or converted from their corresponding SRA runs.

### Processed genomic intervals

- FAIRE-seq peak BED files

The FAIRE datasets are not reprocessed from FASTQ in this workflow. The published peak BED files are downloaded directly and converted from dm3 to dm6.

## Reference files

This module also retrieves:

- dm6 genome FASTA
- dm6 chromosome sizes
- dm6 blacklist
- dm3-to-dm6 liftOver chain

## Output organization

Large downloaded files should not be committed to GitHub.

A suggested local organization is:

```text
data/
├── raw/
│   ├── FlagAntp/
│   ├── GFP_Antp_embryo/
│   └── GFP_Antp_wing_disc/
├── external/
│   └── FAIRE/
└── reference/
    ├── dm6.fa
    ├── dm6.chrom.sizes
    ├── dm6-blacklist.v2.bed
    └── dm3ToDm6.over.chain.gz
```

The `data/` directory should be excluded through `.gitignore`.

## Reproducibility notes

- All Antp datasets used in downstream comparisons must ultimately be represented in dm6 coordinates.
- The published FAIRE peak files are originally in dm3 and are converted to dm6 using UCSC/Kent `liftOver`.
- Public accessions and source information should also be recorded in `config/samples.tsv`, `config/external_datasets.tsv`, and `docs/data_sources.md`.
- Download scripts should use stable accession-based URLs whenever possible.
- Large FASTQ, FASTA, BED, and intermediate files should remain outside version control.
